# jusur-almawared

retheme لملفات تطبيق "عابر القارات" بهوية **جسور الموارد**.
التقرير الكامل في [docs/projects/jusur-almawared/](../../docs/projects/jusur-almawared/README.md).

| الملف | الوصف |
|---|---|
| `project.json` | كل الإعدادات |
| `banners/*.html` | قوالب البانرات (متاخدة من excp-swift-demo ومتظبطة على اللوجو الطولي والثانوي الغامق) |
| `brand/` | *(مش موجود على git)*: `logo-ar.svg` من موقع العميل، و`logo-color.png` و`logo-white.png` و`logo-white.svg` (بيتعملوا بـ `Convert-SvgLogo.ps1`) |
| `project.local.json` | *(مش موجود على git)*: `sourceDir` و`outputDir` |

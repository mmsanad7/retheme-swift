# excp-swift-demo

retheme لملفات تطبيق "عابر القارات" بهوية **الحماية المتميزة**.
التقرير الكامل في [docs/projects/excp-swift-demo/](../../docs/projects/excp-swift-demo/README.md).

| الملف | الوصف |
|---|---|
| `project.json` | كل الإعدادات: الألوان، والصور، واللوجوهات، والبانرات |
| `banners/*.html` | قالب لكل بانر من الخمسة |
| `brand/` | *(مش موجود على git)*: `logo-color.png` (472×103) و`logo-white.png` (312×80) |
| `project.local.json` | *(مش موجود على git)*: `sourceDir` و`outputDir` على جهازك |

# ADR-0001: الريبو public، الأدوات والتوثيق بس

- **الحالة:** مقبول
- **التاريخ:** 2026-11-25

## السياق
الريبو `mmsanad7/retheme-swift` على GitHub عام (public). ملفات العميل فيها خطوط مدفوعة (Helvetica Neue وNeo Sans وShamel) ما ينفعش تتنشر، وفيها كمان صور ولوجوهات بتاعة العميل.

## القرار
بيترفع على الريبو الأدوات والتوثيق والـ config وقوالب البانرات بس. أي ملفات تخص العميل متجاهلة في `.gitignore`:
`projects/*/brand/`، `projects/*/input/`، `projects/*/output/`، `projects/*/.work/`، `projects/*/project.local.json`، وأي صور أو خطوط جوه `projects/`.

## البدائل اللي اتدرست
- **نرفع كل حاجة ما عدا الخطوط:** فيه خطر نشر صور العميل ولوجوهاته من غير إذن.
- **نحوّل الريبو private ونرفع كل حاجة:** صاحب الشغل اختار يسيبه public.

## النتائج
- ✅ مفيش أي خطر قانوني أو خطر على خصوصية العميل.
- ⚠️ على أي جهاز جديد، لازم تجيب الـ assets واللوجوهات بنفسك (الخطوات في [getting-started.md](../getting-started.md)).

# ADR-0002: PowerShell + C# (System.Drawing) من غير Python

- **الحالة:** مقبول
- **التاريخ:** 2026-11-25

## السياق
جهاز الشغل كان Windows ومفيهوش Python ولا Node ولا ImageMagick. واحتجنا معالجة على مستوى البكسل لصور كبيرة (لحد 4900×4900).

## القرار
الكود اللي بيعالج الصور مكتوب C# في `tools/Recolor.cs`، وPowerShell بيعمله compile وقت التشغيل بـ `Add-Type`. القراءة والكتابة بتتعمل بـ `LockBits`، عشان السرعة.

## البدائل اللي اتدرست
- **Python + Pillow:** مكتبة ممتازة، بس محتاجة تسطيب على كل جهاز.
- **ImageMagick:** محتاج تسطيب، وأوامره صعب تتعمل بيها مطابقة الألوان المخصوصة دي.
- **PowerShell بس (GetPixel):** بطيء جدًا.

## النتائج
- ✅ بيشتغل على أي جهاز Windows من غير ما تسطب حاجة.
- ✅ سريع، والصورة الكبيرة بتخلص في ثواني.
- ⚠️ شغال على Windows بس. لو احتجنا macOS أو Linux، هنكتب نسخة Python من الأداة بنفس الـ config.

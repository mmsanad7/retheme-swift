# ADR-0015: القواعد والقرارات ملزمة لأي حد بيشتغل على الريبو، وبتتطبق أوتوماتيك

- **الحالة:** مقبول
- **التاريخ:** 2026-11-26

## السياق
الريبو مشترك بين التيم ليد ورنا (سنيور)، وهو مخزن تراكمي للخبرات والقرارات. التيم ليد طلب إن أي حد يشتغل على الريبو يلتزم بكل القواعد والقرارات، وإنها تتطبق عليه **من أول ما يسحب الريبو**، من غير ما يعتمد على إنه يفتكرها.

git نفسه ما بيشغّلش أي حاجة وقت الـ clone (ده قيد أمان مقصود)، فلازم الفرض يكون من أماكن تانية.

## القرار

### 1. إيه اللي ملزم
- كل القواعد في [CLAUDE.md](../../CLAUDE.md) و[principles.md](../principles.md).
- كل الـ ADRs اللي حالتها "مقبول" في [docs/decisions/](README.md).
- قواعد الفريق في [memory/user-preferences.md](../../memory/user-preferences.md)، وأهمها: **`git pull` قبل أي تعديل، و`git push` بعده**، و**أي اسم ملف أو عنصر في رسالة أو رد يكون رابط**.
- **تغيير أي قاعدة** بيكون بـ ADR جديد يلغي القديم، وبموافقة التيم ليد. ممنوع تتجاهل قاعدة أو تعدّلها من غير ADR.

### 2. إزاي بتتطبق (3 طبقات)

| الطبقة | بتشتغل إمتى | بتعمل إيه |
|---|---|---|
| **Claude Code** ([.claude/settings.json](../../.claude/settings.json)) | أول ما تفتح الريبو في Claude Code | `git pull` أوتوماتيك وتفعيل الـ git hooks ([session-start.ps1](../../tools/hooks/session-start.ps1))، ومش بيخلّي الجلسة تخلص وفيه تعديلات من غير commit أو push ([stop-check.ps1](../../tools/hooks/stop-check.ps1)). و[CLAUDE.md](../../CLAUDE.md) بيتقري لوحده |
| **Git hooks** ([.githooks/pre-commit](../../.githooks/pre-commit)) | أي commit | بيرفض الـ commit لو فيه ملفات عملاء أو سكريبت `.ps1` فيه حروف مش ASCII. بيتفعّل لوحده أول ما تفتح الريبو في Claude Code أو تشغّل أي أداة من `tools/` |
| **GitHub Actions** ([repo-rules.yml](../../.github/workflows/repo-rules.yml)) | أي push أو PR | نفس الفحص على السيرفر، حتى لو حد عدّى الطبقات اللي فوق |

الفحص نفسه في سكريبت واحد: [Test-RepoRules.ps1](../../tools/Test-RepoRules.ps1).

## البدائل اللي اتدرست
- **توثيق بس (CONTRIBUTING):** بيعتمد على إن الشخص يقرا ويفتكر، وده اللي التيم ليد عايز يتجنبه.
- **سكريبت setup يدوي بعد الـ clone:** ممكن يتنسي، فاتفعيل الـ hooks بقى جزء من أول أداة تشتغل ومن جلسة Claude Code.
- **Branch protection وPRs إجبارية:** بيتعارض مع طريقة الشغل الحالية (push مباشر بعد كل تعديل). ممكن نضيفه بعدين بـ ADR جديد.

## النتائج
- ✅ أي حد يسحب الريبو ويشتغل بـ Claude Code أو بالأدوات، القواعد بتتطبق عليه من أول مرة.
- ✅ حتى لو حد عدّى الفحص المحلي، GitHub Actions بيكشفه على السيرفر.
- ⚠️ Claude Code بيطلب موافقة على الـ hooks أول مرة يفتح فيها الريبو (trust). لازم توافق.
- ⚠️ اللي بيعمل commit من غير Claude Code ومن غير ما يشغّل أي أداة، الـ hooks مش هتتفعّل عنده لحد ما يشغّل أداة، أو ينفّذ: `git config core.hooksPath .githooks`. بس GitHub Actions هيكشف أي مخالفة.

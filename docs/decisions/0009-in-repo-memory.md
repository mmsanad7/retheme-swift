# ADR-0009: الذاكرة جوه الريبو (CLAUDE.md + memory/)

- **الحالة:** مقبول
- **التاريخ:** 2026-11-25

## السياق
صاحب الشغل بيشتغل على أكتر من جهاز، وممكن زميل يكمّل الشغل. ذاكرة Claude Code العادية محفوظة على الجهاز نفسه بس (`~/.claude/...`)، فما بتتنقلش.

## القرار
- `CLAUDE.md` في أول الريبو: فيه القواعد والأوامر، وبيعمل import لملفات `memory/`. Claude Code بيقراه لوحده في أي جلسة.
- `memory/`: فيه التفضيلات والدروس وسجل المشاريع، بالعربي.
- القرارات اللي ليها بدائل بتتكتب في `docs/decisions/`.

## البدائل اللي اتدرست
- **ذاكرة على الجهاز بس:** ما بتتنقلش لجهاز تاني.
- **wiki على GitHub:** منفصلة عن الكود، وClaude مش بيقراها لوحده.

## النتائج
- ✅ `git pull` على أي جهاز بيجيب الذاكرة كلها.
- ⚠️ الريبو public، فممنوع يتكتب فيها أي بيانات شخصية أو سرية.

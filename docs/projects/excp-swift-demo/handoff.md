# تسليم لفريق التطوير: الحماية المتميزة

الملف ده لفريق تطوير التطبيق (Flutter). بيعرّفكم بالهوية الجديدة، واستلمتوا إيه بالظبط، وإيه اللي لسه محتاج يتعمل في الكود.

> اتكتب بعد التسليم (2026-11-26)، لما `handoff.md` بقى إلزامي لكل مشروع ([ADR 0018](../../decisions/0018-workspace-layout-and-project-scaffold.md)). كل المعلومات مأخوذة من [تقرير المشروع](README.md).

## 2. استلمتوا إيه

فولدر **`excp swift demo assets`**: بديل مباشر لفولدر `assets` الحالي.

- **204 ملف** بنفس الأسماء ونفس المسارات ونفس الصيغ ونفس المقاسات، مفيش منهم ملف اتشال أو اتغير اسمه ([ADR 0008](../../decisions/0008-preserve-names-formats-dimensions.md)).
- **77 ملف اتعدل** و**127 زي ما هم**. القائمة الكاملة بالأسماء في [changed-files.md](changed-files.md).

| النوع | اتعدل | زي ما هو | اتعدل إيه |
|---|---|---|---|
| SVG | 63 | 100 | ألوان البراند القديم بقت ألوان الحماية المتميزة، و`images/auth/brand_logo.svg` فيه اللوجو الجديد |
| صور PNG/JPG | 14 | 14 | 7 رسومات اتغيرت ألوانها، و2 لوجو، و5 بانرات اتعاد تصميمها |
| خطوط | 0 | 9 | — |
| JSON وLottie | 0 | 4 | — |

### أهم الملفات
| الملف | التغيير |
|---|---|
| `images/logo.png` و`lottie_files/logo.png` | اللوجو الجديد بالألوان، بنفس المقاس 723×720 (عشان الأنيميشن) |
| `images/auth/brand_logo.svg` | اللوجو الجديد (شاشة الدخول) |
| `images/slider1.png` لحد `slider4.png` و`images/default_slider.jpeg` | البانرات بالاسم واللوجو والألوان الجديدة، وبنفس الرسالة الإعلانية |
| `images/onboarding_1-3.png` و`icon/empty_icon.png` و`images/add_ticket.png` وغيرهم | الرسومات بالألوان الجديدة |

### إزاي تركّبوه
1. استبدلوا محتوى فولدر `assets` بمحتوى `excp swift demo assets`.
2. مسارات الملفات زي ما هي، فمش محتاجين تعدلوا `pubspec.yaml`.
3. اعملوا `flutter clean` قبل الـ build، عشان الصور القديمة ما تفضلش في الكاش.

## 3. المطلوب منكم في الكود

الحاجات دي **مش جوه فولدر الـ assets**، فما اتعدلتش من عندنا:

- [ ] **ألوان الثيم في كود Dart.** استبدلوا ألوان البراند القديم بالجديدة:

  | القديم | الجديد |
  |---|---|
  | `#224182` كحلي (الأساسي القديم) | `#21A085` |
  | `#12AAE3` / `#1BAAE2` أزرق فاتح (الثانوي القديم) | `#B1C91F` |
  | `#8DC43E` أخضر اللوجو القديم | `#B1C91F` |
  | `#EDF3FD` خلفية فاتحة | `#EAF6F3` |

  أي ظل تاني من الألوان دي موجود في [project.json](../../../projects/excp-swift-demo/project.json) (`svg.colorMap`).
- [ ] **اسم التطبيق** في Android (`android:label`) وiOS (`CFBundleDisplayName`).
- [ ] **أيقونة التطبيق (launcher icon) والـ native splash**: مش من ضمن التسليم ده.
- [ ] **النصوص وملفات الترجمة** اللي فيها "عابر القارات" أو "البلاد" أو بيانات تواصل قديمة.
- [ ] **`lottie_files/splash_lottie.json`** اتنقل زي ما هو. اتأكدوا إن الأنيميشن مفيهوش ألوان أو اسم قديم.

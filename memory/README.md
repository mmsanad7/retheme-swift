# الذاكرة الداخلية (memory/)

الفولدر ده بيحفظ اللي اتعلمناه وما ينفعش يتعرف من الكود لوحده:
تفضيلات صاحب الشغل، والدروس، وسجل المشاريع. لأنه جوه الريبو، بيتنقل مع `git pull` لأي جهاز أو زميل.

| الملف | فيه إيه |
|---|---|
| [user-preferences.md](user-preferences.md) | طريقة الشغل والقواعد اللي صاحب الشغل حددها |
| [lessons-learned.md](lessons-learned.md) | مشاكل حصلت وإزاي اتحلت، عشان ما تتكررش |
| [project-log.md](project-log.md) | سجل زمني للمشاريع والقرارات المهمة |

## إزاي تحدّثها

- **تفضيل أو قاعدة جديدة** من صاحب الشغل → `user-preferences.md` (اكتب السبب).
- **مشكلة اتحلت** → `lessons-learned.md` بالشكل: المشكلة / السبب / الحل.
- **مشروع خلص أو قرار كبير** → سطر في `project-log.md` بالتاريخ الكامل (مش "امبارح").
- **قرار تقني له بدائل** → ADR في `docs/decisions/` واربطه من هنا.

ممنوع تكتب هنا بيانات شخصية (إيميلات، أرقام تليفون، كلمات سر) — الريبو public.
